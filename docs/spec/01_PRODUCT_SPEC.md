# Product Specification

## Product
Voice Leading Lab is a serious piano learning and harmonic-analysis environment. The core idea is horizontal: chords are snapshots of moving voices.

## Main areas
Home; Learn; Practice; Visualizer; Lab; Barry Harris; Ear Training; Free Play; Progress; Instruments/Settings.

## Primary flow
Connect MIDI keyboard -> choose instrument -> select lesson/exercise/lab -> play -> assign notes to voices -> analyze movement -> display notation/keyboard/voice graph -> give specific deterministic feedback -> store competency evidence.

## Core features
- Live MIDI input and sustain tracking.
- Voice-path visualizer.
- Grand-staff notation with normal proportions.
- Chord labels as secondary descriptors.
- Voice isolation and slow playback.
- Nearest-voicing solver.
- Guide-tone and ii-V-I trainer.
- Melody harmonizer.
- Inner-line lab.
- Reharmonization lab with lockable voices.
- Barry Harris sixth-diminished and related systems.
- Ear training for individual voices.
- Free-play post-analysis.
- Book linkage by permanent concept IDs.
- Competency states: Not Started, Introduced, Developing, Reliable, Fluent.

## Instrument set
Acoustic: concert grand, studio grand, upright, felt/intimate.
Electric: Stage Rhodes-style, Suitcase Rhodes-style, dark jazz Rhodes, bright/bell Rhodes, clean Wurlitzer-style, driven Wurlitzer-style.

## Non-goals for MVP
No DAW, social network, streaks/XP, leaderboards, cloud requirement, microphone transcription, or full notation-editor scope.
