# UI / UX

Desktop-first, serious, restrained, modern. Avoid game aesthetics, giant cards, decorative keyboards, oversized notation, and stretched staff systems.

## Main workspace
Left: navigation/lesson/exercise list.
Center: notation + voice graph + keyboard.
Right: analysis, constraints, instrument controls. Panels collapsible.

## Voice graph
Horizontal axis = time/events. Vertical axis = pitch. Continuous line per voice. Select/isolate any voice, label interval movement, show stationary/semitone/step/leap markers, faint chord-event overlays, zoom. Do not rely only on color.

## Notation
Conventional engraving, compact systems, normal note spacing, collision avoidance, grand staff, accidentals, ledger lines, optional fingering and highlights. User can change notation size and toggle labels/analysis marks. Never stretch short phrases across a huge width.

## Keyboard
Only show it when it conveys information: held notes, targets, voices, guide tones, locked notes, Barry Harris family/borrowed notes. Never generic decorative octave diagrams.

## Instrument UI
Quick: preset, volume, tone, reverb, macros.
Workshop: tuning, velocity, EQ, detailed instrument parameters, FX, save preset.
