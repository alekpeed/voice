# Curriculum and Exercise System

## Stable IDs
Canonical concept ID: VL-<section>.<concept>. Exercise: VL-<section>.<concept>-<exercise>. Never renumber released IDs.

## Learning sequence
A Fundamental Motion: independent voices, step/skip/leap, contrary/similar/parallel/oblique, common tones, register, spacing, crossing.
B Tendency/Resolution: leading tone, chordal seventh, semitone attraction, suspensions, neighbors, anticipations, chromatic approaches.
C Triads: inversions, common-tone connection, I-IV-V-I, diatonic progressions, bass vs upper voices.
D Seventh Chords: guide tones, ii-V-I, turnarounds, rootless logic.
E Inner Voices: melodic inner lines, pedals, line clichés, predetermined soprano/bass.
F Chromatic Voice Leading: diminished connectors, secondary dominants, tritone substitutions, chromatic approaches, common-tone diminished.
G Jazz Voice Leading: shells, rootless voicings, extensions, alterations, spread structures.
H Barry Harris integration.
I Reharmonization.
J Solo piano textures.

## Exercise types
Reproduce; Complete; Nearest Voicing; Fixed Soprano; Fixed Bass; Guide Tones Only; Add Voices; Identify Motion; Harmonize Melody; Reharmonize; Transpose; Free Construction.

## Adaptive difficulty
Increase voices, remove visual scaffolding, widen key range, increase tempo, prescribe melody, add alterations/chromaticism, remove chord labels, or use ear-only prompts.

## Competency
Not Started, Introduced, Developing, Reliable, Fluent. Estimate from successful constraint satisfaction, hints, all-key performance, stability over sessions, and success without scaffolding. Never from time spent or streaks.
