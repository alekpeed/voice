# Voice Leading Lab — Coder Pack

Desktop-first piano training app centered on voice leading, with a substantial Barry Harris module and high-end instrument audio.

Non-negotiables: MIDI keyboard first; deterministic music engine before AI; realistic acoustic piano/Rhodes/Wurlitzer audio; compact conventional notation; no gamification; stable book concept IDs; offline core functionality.

Recommended stack: C++20 + JUCE + CMake + SQLite + a professional notation renderer + an SFZ/sample or hybrid instrument engine. Other stacks are acceptable only if the subsystem boundaries in this pack are preserved.

Read in order: PRODUCT_SPEC, ARCHITECTURE, MUSIC_ENGINE, AUDIO_ENGINE, CURRICULUM, BARRY_HARRIS, UI_UX, BUILD_PHASES, TESTING, CODER_MASTER_PROMPT.
